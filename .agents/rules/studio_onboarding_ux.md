# Studio Onboarding & Configurator UX Standards

When designing website builders, configurators, or client onboarding flows:

1. **Landing Stage**:
   - The entry screen must be clean, animated, and uncluttered.
   - Center on a bold, high-impact action (e.g., "CREATE WEBSITE") with kinetic typography or canvas motion rather than long paragraphs or text explanations.

2. **Single-Question Principle**:
   - Each step must present exactly **ONE** question.
   - Offer 3–4 concise, visual multiple-choice option cards and an optional write-in input field.
   - Do NOT stack multiple unrelated configuration questions or long form fields on the same screen.

3. **Immediate Visual & Sensory Representation**:
   - Whatever is being asked must immediately be demonstrated live on that page.
   - If asking about 3D shapes $\rightarrow$ the 3D geometry morphs in real-time.
   - If asking about color $\rightarrow$ the viewport lighting and palette shifts instantly.
   - If asking about animations $\rightarrow$ animate the page and provide a "Test Impulse / Bounce" trigger.
   - If asking about audio $\rightarrow$ synthesize an instant audio sample via the Web Audio API.

4. **No Academic or Jargon Overload**:
   - Avoid overwhelming the user with heavy design theory, CSS guides, or technical research in the UI copy.
   - Keep choices intuitive, visual, and experiential so the user can see and feel what they are picking.
